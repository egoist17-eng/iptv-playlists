## Как проверяли (финальный проход)

Перепроверены все 847 уникальных URL из исходных плейлистов
(`IPTVstable.m3u8` + `IPTVdonor.m3u`) по 5 критериям сразу:

1. HLS master → вложенный плейлист → реальный видеосегмент.
2. Сегмент скачивается, размер > 1 КБ, есть MPEG-TS sync byte `0x47`.
3. Нет `Content-Encoding: gzip` ни на одном уровне (VIDAA не умеет распаковывать).
4. Нет `#EXT-X-KEY` с `METHOD=AES-128` (VIDAA не играет шифрованные потоки).
5. Нет редиректов на `/blocked/`, рекламных хостов и HEVC/AV1.

Результат: `ok=505`, `no_segment=270`, `reject=72`.
Отдельно заново проверены все 63 HD-потока — все прошли.
После дедупликации по названию (с сохранением HD и таймшифтов) — **421 канал**.
Дополнительно исключены:
- все `cdn.ntv.ru` / `cdn2.ntv.ru` (периодически gzip);
- `starcius-cinema.com` и каналы с тестовыми токенами — поток технически
  играет, но на экране появляется «Отсутствует подписка» (VeleS, Viasat Kino
  и др.). Проверка сегментов такую подпись не ловит.

Отсеянные причины: `blocked_redirect=41`, `ad_host=41`, `gzip=34`,
`no_sync=19`, `seg_small=16`, `seg_http404=10`, `seg_http403=5`, `aes128=2`, `hevc=1`.

## Что НЕ получилось добавить

- `cinerama.uz` — показывал полноэкранную рекламу вместо канала. Заблокирован
  на роутере только для ТВ (MAC 88:b8:63:74:a6:a9) и удалён из списка.
- `cdn.ntv.ru` — отдаёт gzip-плейлисты, VIDAA их не открывает. НТВ добавлен
  с `ngenix.net` (НТВ, НТВ +1/+2/+4/+7).
- «Кинопремьера», «Киносвидание», «Киноужас» — платные каналы NTV+/WINK,
  в бесплатных источниках отсутствуют.
- «Первый канал» и «Россия 2» в открытом HLS не найдены; есть «Первый канал +2»
  и «Россия 1/К/24». Их HD-версии тоже недоступны (только DASH/MPD,
  который VIDAA не играет).
- VeleS, Viasat Kino, Nat Geo Wild HD, Trash HD требуют подписку — удалены.

## Добавление в SS IPTV

Удалите старый плейлист из «Мой плейлист», затем добавьте заново:

```
https://raw.githubusercontent.com/egoist17-eng/iptv-playlists/main/IPTV-test5.m3u
```

Если все 5 каналов заработают — замените на основной:

```
https://raw.githubusercontent.com/egoist17-eng/iptv-playlists/main/IPTV-200.m3u
```

Если какой-то канал не идёт — напишите его название и что именно на экране.
Автопроверка гарантирует только техническую исправность потока, а не то,
что VIDAA его корректно воспроизведёт.
