# IPTV-плейлисты для VIDAA / SS IPTV

Дата проверки: 22.11.2026 (третья проверка после жалобы на НТВ).

## Важно

Старый список содержал каналы с `stream8.cinerama.uz`. Этот хост перенаправляет
на `cache1.cinerama.uz/blocked/` и показывает полноэкранную рекламу вместо канала.
Все такие каналы удалены. Дополнительно домены `cinerama.uz` и
`cache1.cinerama.uz` добавлены в блокировку DNS только для телевизора
(MAC 88:b8:63:74:a6:a9) на роутере.

Вторая проблема: `cdn.ntv.ru` отдаёт master-плейлисты с `Content-Encoding: gzip`.
VIDAA не умеет распаковывать такие плейлисты, поэтому НТВ не запускался.
Все каналы с `cdn.ntv.ru` / `cdn2.ntv.ru` заменены на НТВ с `ngenix.net`
(CH_NTV, CH_NTV_2, CH_NTV_4, CH_NTV_7) — тот же CDN, на котором СТС,
Россия 1 и 2x2 у вас уже работают. Проверено: `Content-Encoding` отсутствует,
`METHOD=NONE`, видеосегмент скачивается.

## Как проверяли

1. Первый проход: загрузка плейлиста и вложенного, 847 ссылок → 568 кандидатов.
2. Второй проход: рекурсивный обход HLS до медиа-сегмента, 551 кандидат.
3. Третий проход: скачивание видеосегмента и проверка MPEG-TS sync byte (0x47).
4. Четвёртый фильтр: только официальные CDN вещателей. Исключены реселлеры
   и рекламные площадки: cinerama.uz, thestream.cyou, sofast.tv, ott.watch,
   teleport.cc, tuva.ru, cloudfront.net, facecast, IP-хосты.
5. Пятый проход: проверка `Content-Encoding` у всех 206 каналов — найдены 4
   gzip-плейлиста (все NTV). Замены на ngenix проверены.
6. Шестой проход: проверка `#EXT-X-KEY` — шифрование AES-128 отсутствует.
7. Итог: 203 канала, 0 gzip, 0 AES-128, 0 рекламных хостов.

## Состав

- Федеральные РФ: ~29 — НТВ, НТВ +2/+4/+7, Первый канал +2, Россия 1/К/24,
  СТС, ТНТ, 2x2, Матч!, Пятый канал, Звезда, Мир, ТВ Центр +2, Рен ТВ, ТВ3,
  Домашний, Карусель, МУЗ-ТВ +2 и др.
- Региональные и прочие: ~174 — проверены по сегментам, но на VIDAA не тестировались.
- Кино-, детские и познавательные каналы из свободных плейлистов почти все
  оказались на рекламных хостах и удалены.

## Добавление в SS IPTV

Удалите старый плейлист из «Мой плейлист», затем добавьте заново:

```
https://raw.githubusercontent.com/egoist17-eng/iptv-playlists/main/IPTV-test5.m3u
```

Если 5 тестовых каналов заработают (включая НТВ), замените ссылку на основную:

```
https://raw.githubusercontent.com/egoist17-eng/iptv-playlists/main/IPTV-200.m3u
```
