# IPTV-плейлисты для VIDAA / SS IPTV

Дата проверки: 2026-11-22.

## Файлы

| Файл | Что внутри |
|---|---|
| `IPTV-200.m3u` | Основной список: 200 отобранных каналов. Рекомендуется для SS IPTV. |
| `IPTV-full.m3u` | Полный список: 378 каналов, включая региональные. |
| `TEST-5.m3u` | Тестовый список из 5 каналов, если нужно проверить плеер. |

## Как проверить

Каждая ссылка проверялась в два этапа:

1. Загрузка плейлиста и вложенного медиа-плейлиста (до 4 уровней).
2. Повторная проверка отобранных ссылок перед публикацией.

Отсеяны: мертвые ссылки, HTTP 403/404/503, пустые плейлисты, потоки без сегментов,
радио и аудио, raw MPEG-TS/UDP, DASH/MPD (VIDAA их не играет), HEVC/AV1,
а также домены, заблокированные на роутере для телевизора.

## Замечание

Каналы «Кинопремьера», «Киносвидание», «Киноужас» — платные каналы NTV+/WINK.
В свободных публичных плейлистах они отсутствуют. Вместо них в списке есть
рабочие бесплатные каналы схожей тематики: Horror TV, Дом Кино, КиноСезон,
Советское кино, Еврокино, Кино 1, KinoKazka, Комедия, НТВ Сериал, НТВ Хит.

## Добавление в SS IPTV

Скопируйте ссылку на raw-файл:

```
https://raw.githubusercontent.com/egoist17-eng/iptv-playlists/main/IPTV-200.m3u
```

В SS IPTV: «Мой плейлист» → добавить по ссылке → вставить → сохранить.
Если нужен полный список, замените `IPTV-200.m3u` на `IPTV-full.m3u`.
