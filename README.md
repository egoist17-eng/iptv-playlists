# IPTV-плейлисты для VIDAA / SS IPTV

Дата проверки: 22.11.2026 (вторая проверка после жалобы на рекламу).

## Важно

Старый список содержал каналы с `stream8.cinerama.uz`. Этот хост перенаправляет
на `cache1.cinerama.uz/blocked/` и показывает полноэкранную рекламу вместо канала.
Все такие каналы удалены. Дополнительно домены `cinerama.uz` и
`cache1.cinerama.uz` добавлены в блокировку DNS только для телевизора
(MAC 88:b8:63:74:a6:a9) на роутере.

## Как проверяли

1. Первый проход: загрузка плейлиста и вложенного, 847 ссылок → 568 кандидатов.
2. Второй проход: рекурсивный обход HLS до медиа-сегмента, 551 кандидат.
3. Третий проход: скачивание самого видеосегмента и проверка MPEG-TS sync byte
   (0x47) и размера. Из 370 отобранных — 358 прошли.
4. Четвёртый фильтр: только официальные CDN (`cdn.ntv.ru`, `cdnvideo.ru`,
   `ngenix.net`, `tvzvezda.ru`, `rutube.ru`, `bonus-tv.ru`, `beltelecom.by`,
   `mediacdn.ru`, `1tvcrimea.ru`, `otcnet.ru`, `vintera.tv`).
   Исключены все реселлеры и рекламные площадки: cinerama.uz, thestream.cyou,
   sofast.tv, ott.watch, teleport.cc, tuva.ru, cloudfront.net и IP-хосты.
5. Итог: 206 каналов с подтверждёнными видеосегментами.

Ограничение: автоматическая проверка не может гарантировать, что на экране ТВ
показывается именно эфир канала, а не заставка/реклама. Поэтому оставлен
маленький тестовый список — проверьте его на телевизоре в первую очередь.

## Состав

- Федеральные РФ: 32 — Первый канал +2, Россия 1/К/24, НТВ, СТС, ТНТ, 2x2, Матч!, Пятый канал, Звезда, Мир, ТВ Центр +2, Рен ТВ, ТВ3, Домашний, Карусель, МУЗ-ТВ +2 и др.
- Кино, детские, познавательные и зарубежные каналы из свободных плейлистов
  почти все оказались на рекламных/реселлерских хостах и удалены.
  Остались только каналы с официальных CDN.

## Добавление в SS IPTV

Удалите старый плейлист из «Мой плейлист», затем добавьте заново:

```
https://raw.githubusercontent.com/egoist17-eng/iptv-playlists/main/IPTV-test5.m3u
```

Если 5 тестовых каналов заработают — замените ссылку на основную:

```
https://raw.githubusercontent.com/egoist17-eng/iptv-playlists/main/IPTV-200.m3u
```
