## Как проверяли

Новый источник: `https://iptv.org.ua/iptv/iptv.m3u` — 2110 записей,
из них отобраны группы SPORT, 18+, KINO+, POZNAVATELNYE, DETSKIE,
Uplink/Квант/Оргтехсервис/Uspeh/Internet42/Тест и др. (1168 кандидатов).
`uv.check` прошли 418. После отсева явных 18+ и дублей отобрано 111 каналов,
из них финальную проверку сегмента на H.264 (SPS `0x67`, без HEVC VPS `0x40`)
прошли 80.

Основной список дополнительно проверен по 5 критериям:
1. HLS master → вложенный плейлист → реальный видеосегмент.
2. Сегмент скачивается, размер > 1 КБ, есть MPEG-TS sync byte `0x47`.
3. Нет `Content-Encoding: gzip` ни на одном уровне (VIDAA не умеет распаковывать).
4. Нет `#EXT-X-KEY` с `METHOD=AES-128`.
5. Нет редиректов на `/blocked/`, рекламных хостов и HEVC/AV1.

Ранее: `ok=505`, `no_segment=270`, `reject=72`.
Отсеянные причины: `blocked_redirect=41`, `ad_host=41`, `gzip=34`,
`no_sync=19`, `seg_small=16`, `seg_http404=10`, `seg_http403=5`,
`aes128=2`, `hevc=1`.

## Что НЕ получилось добавить

- `cinerama.uz` — полноэкранная реклама вместо канала. Заблокирован на
  роутере только для ТВ (MAC 88:b8:63:74:a6:a9) и удалён из списка.
- `cdn.ntv.ru` / `cdn2.ntv.ru` — gzip-плейлисты. НТВ взят с `ngenix.net`.
- `starcius-cinema.com`, `token=010101010101`, `token=test` — «Отсутствует
  подписка» на экране.
- Horror TV, webcaster `Старт*`, `ТВ Спорт` — технически играют, но VIDAA
  не воспроизводит.
- Большинство 18+ из iptv.org.ua — явные хардкор-каналы, не подходят под
  наши критерии. Из доступных мейнстримных рабочие только мягкие эротические.

## Добавление в SS IPTV

Удалите старый плейлист из «Мой плейлист», затем добавьте заново:

```
https://raw.githubusercontent.com/egoist17-eng/iptv-playlists/main/IPTV-test5.m3u
```

Если все каналы из тестового списка заработают — замените на основной:

```
https://raw.githubusercontent.com/egoist17-eng/iptv-playlists/main/IPTV-200.m3u
```

Если какой-то канал не идёт — напишите его название и что именно на экране.
Автопроверка гарантирует только техническую исправность потока, а не то,
что VIDAA его корректно воспроизведёт.
